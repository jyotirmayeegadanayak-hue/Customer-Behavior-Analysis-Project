# 📊 Customer Behavior & Shopping Trends Data Analytics Project

An end-to-end data analytics project exploring consumer purchasing patterns, demographic trends, and product performance using **Python**, **PostgreSQL 18**, and **Power BI**.

---

## 🚀 Project Overview
Understanding consumer behavior is vital for retail optimization. This project analyzes customer shopping habits to uncover actionable business insights, evaluate membership programs, and track key performance metrics through an interactive executive dashboard.

---

## 🛠️ Tech Stack & Tools
- **Python (Jupyter Notebook):** Data ingestion, validation, and preprocessing (`customer analysis`).
- **PostgreSQL 18 & pgAdmin 4:** Relational database management (`customer_behavior`) and complex SQL query analysis.
- **Power BI Desktop:** Interactive dashboard design and KPI visualization.
- **Git & GitHub:** Version control and professional portfolio presentation.
